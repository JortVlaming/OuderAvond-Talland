Basis JavaScript

JavaScript is een programmeertaal die wordt gebruikt om functie te geven aan webpagina's

Knoppen

Knoppen zijn elementen die wanneer er op wordt geclicked een functie in javascript kan activeren

Knoppen bestaan uit <button> elementen

Om de functie te bepalen die de knop activeerd wordt de attribute onclick="" gebruikt


Bijvoorbeeld: <button onclick="voorbeeld()">Ik ben een knop!</button> word

En met een beetje code kan je deze tekst veranderen als je op de knop klikt

Ik wordt veranderd!

Functions

Functions zijn bedoeld om een code te schrijven en die in 1 keer aan te roepen. Functions hebben parameters nodig die zet je tussen de ()

Parameters zijn de variavblen die je meegeeft als je de functie aan roept

Je maakt een function door: function "naam van de functio" (Parameter){}, en je roept een functie aan door: Functie naam(variablen die je als parameter wilt gebruiken).

Je moet met js als je (bijvoorbeeld knoppen gebruikt) elementen aanspreken op een manier.

Deze manier gaat als volgt: document.getElementById("id");.

Als je wilt dat deze knop een kleur krijgt als je er op klikt moet je: .style.backgroundColor="kleur" er nog achter zetten.

En als je een datum zou willen ophalen zou je: .innerHTML = date(); kunnen gerbuiken.
